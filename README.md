# Настройки Tronxy XY-100 

Репозиторий служит хранилищем полезных файлов для работы, ремонта и возможно модернизации принтера **Tronxy XY-100**.

## 📦 Содержимое 📦
### 📂 Папка `Marlin` 📂

Содержит все необходимые файлы для прошивания принтера со следующими компонентами:
- Плата управления: `Melzi v2`;
- Драйверы шаговых двигателей: `A4988`;
- Экран: `C2004A`.

Версия прошивки выбрана v1.1, так как остальные более новые не получилось установить.
